# Documentação

- `GUIA.md` — como rodar, como treinar e o que falta fazer.
- `adr/` — decisões de arquitetura, numeradas e em ordem cronológica.
  Uma decisão relevante vira um ADR curto: contexto, decisão,
  alternativas, consequências.
- A documentação técnica completa (arquitetura, camada facial, modelo de
  dados, corpus, avaliação, ética) ainda está em documento externo e será
  migrada para cá, que é onde ela fica versionada junto com o código.
